UPLOAD:
1. Extract EquipmentHub-GitHub-Ready.zip.
2. Open your GitHub repository.
3. Upload ALL files inside the extracted folder directly to the repository root.
4. Commit to main.
5. GitHub Settings -> Pages:
   Source: Deploy from a branch
   Branch: main
   Folder: /(root)
6. Wait for deployment to finish.
